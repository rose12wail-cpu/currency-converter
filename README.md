# Currency Converter

A simple, responsive web app for converting between 150+ currencies, with a 7-day exchange rate chart.

**Live demo:** https://rose12wail-cpu.github.io/currency-converter/

## Features

- Convert between 150+ currencies using up-to-date exchange rates
- 7-day rate history shown in a line chart
- Swap currencies with one click
- Remembers your last selected currencies
- Automatic dark mode and mobile-friendly layout
- Error handling when the network or API is unavailable

## Built With

- HTML, CSS, JavaScript (vanilla)
- [Chart.js](https://www.chartjs.org/) for the chart

## APIs

- [open.er-api.com](https://www.exchangerate-api.com/docs/free) for current exchange rates
- [fawazahmed0/currency-api](https://github.com/fawazahmed0/exchange-api) for historical rates, with a fallback URL if the primary one fails
